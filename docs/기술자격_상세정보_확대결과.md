- 저장된 510개 전체의 입력 모델·단계 일치·확인 상태·출처·원본 시각 검증 통과.
- 대표 16개 실제 HTTP 응답 검증 통과: 기사·산업기사·기능사·기술사·실기 단독·부분 수집·미수집 포함.
- 기본 자동 테스트 71개 실행: 69개 통과, DB 설정이 필요한 2개 기본 실행에서 제외. 상세정보 DB 통합 테스트는 Render 임시 스키마에서 별도 실행하고 롤백하여 통과.
- 부분 저장이 기존 값을 지우지 않는지, 출처 시각이 없는 응시료도 나중에 정상 갱신되는지 확인.
