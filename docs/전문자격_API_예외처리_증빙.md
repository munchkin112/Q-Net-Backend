## 주장할 수 있는 범위

이 자료는 **공식 데이터 수집 코드의 오류 처리와 제한된 재시도**를 입증한다. 전문자격 사용자 API, LangGraph의 검증·수정·재실행 흐름, RAG 자동 Fallback의 구현 완료를 입증하는 자료로 사용하지 않는다.

빈 응답을 종목 폐지·미시행의 근거로 사용하지 않는다. 오류코드 99의 제공기관 내부 원인을 별도로 확정하지 않는다. 시간초과 요청은 서버 응답을 받지 못했으므로 원본 XML이 없고, 요청 메타데이터가 증빙이다.

최초 공식 페이지 대체 수집 기록은 실제 본문 확보 여부가 미확정이었다. 하단의 추가 표본 조사에서는 시험정보 본문 탭을 직접 확인한 결과를 별도로 기록했다. `professional_fallback_sources.json`의 `usable_information_confirmed=false`를 유지하며 정상 API 원본을 대체했다고 주장하지 않는다.

단위테스트 재실행 명령:

```powershell
.\.venv\Scripts\python.exe -m unittest research.test_preparation -v
```


## 추가 원인 조사 — 유형별 2종목 표본

조사일: 2026-10-06 (Asia/Seoul). 빈 응답·오류코드 99·시간초과에서 각각 2종목, 총 6종목을 임의 선정했다. 다른 실패 종목 전체를 다시 조사하지 않았다. 동일 요청 방식의 비교를 위해 공인중개사(9630)를 정상 대조군 1종목으로 조회했다.

### 조사 방법과 통제 조건

- 최초 집계의 `professional_sources.json`과 44종목 CSV는 그대로 보존했다. 아래 결과는 별도의 재조회 기록이다.
- 실제 상세 API 주소와 `jmCd` 파라미터는 [공식 명세](https://www.data.go.kr/data/15003003/openapi.do)와 대조했다. 선정 종목은 보관한 공식 목록에 있는 코드다.
- 이전 수집과 같은 URL·종목 코드·GET 요청 방식·20초 제한을 사용했고 API 재시도는 최대 1회였다. 정상 빈 결과는 반복하지 않았다.
- API와 별도로 공식 시험정보 본문 탭 `crf00503s02`를 조회해 API 원본의 누락과 공식 웹 정보의 존재를 구분했다. 전체 화면 `crf00503`의 메뉴·외곽 화면만으로 상세 정보 확보를 판단하지 않았다.
- 청소년상담사 2·3급은 별도 진단 요청을 각각 1회 실행하여 TCP 접속·요청 전송·응답 헤더 수신 단계를 기록했다. 이 통신 단계 진단은 애플리케이션의 자동 재시도 횟수를 변경하지 않는다.
- 공식 명세는 `ServiceKey`를 필수로 설명한다. 이번 재현은 최초와 동일한 인증키 미전송 공개 엔드포인트 경로다. 같은 방식의 대조군 공인중개사는 00·3개 항목을 반환했지만, 모든 종목의 인증 원인을 배제하거나 인증 없는 운영을 보장하는 근거로 사용하지 않는다.

위 해석 중 제공기관 내부 장애·데이터 연계 누락의 구체적인 원인은 추정 또는 미확정이다. HTTP/결과코드·원본 항목 수·웹 정보 존재·통신 단계 관측을 확인 사실로 구분했다. 이 6종목의 결과를 나머지 38종목에 일괄 적용하지 않는다.

### 청소년상담사 3급 통신 단계 증거

```text
TCP 연결 완료                     0.222초
요청 헤더·본문 전송 완료          0.223초
응답 헤더 수신 대기 시작          0.223초
응답 헤더 수신 실패(ReadTimeout) 20.222초
```

이 trace는 별도 진단 요청의 관측값이다. 과거 urllib TimeoutError 요청과 동일한 요청이었다고 소급해서 주장하지 않는다. 타임아웃 요청에는 서버 응답 원본이 없으므로 trace·오류명·조회 시각을 증빙으로 사용한다.
