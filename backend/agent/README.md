# Agent 개발 위치

LangGraph·LangChain을 연결할 기본 패키지다. 현재 실행 Graph와 Agent API는 구현하지 않았다.

구현할 때 다음 파일을 필요한 순서대로 추가한다.

| 파일 | 역할 |
| --- | --- |
| `state.py` | 실제 실행에서 사용하는 작업 상태 |
| `tools.py` | 기존 DB·공식 자료 조회 함수 연결 |
| `nodes.py` | LLM 판단·도구 실행·결과 검증 |
| `graph.py` | 노드 연결·분기·제한된 재시도 |

현재 사용자 결정: 챗봇 없이 관심 분야 기반으로 실제 후보 중 최대 3개를 순위 없는 목록으로 제시한다. 후보가 1~2개면 확보한 수만 표시하고 없으면 없음 안내를 한다.

날짜·권한·중복 검사는 Python이 맡고, LLM은 공식 자료에 없는 사실을 만들지 않는다. 아직 쓰지 않는 State 필드나 기능을 미리 추가하지 않는다.
